# Security

Please report security problems privately to **info@pattern-ai.com** with "Security" in the subject. Don't
open a public issue. Include what you found, how to reproduce it, and what it affects. We'll reply within a few
working days and tell you when it's fixed.

Scope: the joinfor.me service (`joinfor.me`, `app.joinfor.me`, `api.joinfor.me`, the MCP server and the API) and
the files in this repository.

Please don't access other people's data, disrupt the service, or send bots into meetings you weren't invited
to while testing.

If an API key leaks, revoke it right away at https://app.joinfor.me/account (API keys) and create a new one.
